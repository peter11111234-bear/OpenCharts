技術指標研究筆記（一）

ATR、ADX、DMI（PDI/MDI）與 CHOP 實戰量化體系 · 專案落地研究

日期：2026-10-18 · 對標代碼：TRIS390.pine ＆ jev-shadow.py

體系總覽 DMI (PDI/MDI) ADX 趨勢強度 CHOP 碎形指標 雙重共振過濾 週期框架 程式碼實作落地

1. 四大核心指標量化體系總覽

在趨勢追蹤（Trend Following）與突破交易中，最常造成虧損的主因並非「方向猜錯」，而是「在錯誤的環境做單」——即**在無方向的洗盤泥淖中頻繁順勢追價，導致多空反覆雙巴**。本套體系利用四大指標分工形成立體防護網：

指標 英文全稱 衡量目標 核心功能 警戒/關鍵閥值
ATR Average True Range 真實振幅 動態停損距離計算、波動率擴張/壓縮判定 相對歷史百分位
PDI (+DI) Plus Directional Indicator 多方攻擊力道 衡量向上突破動能，辨別漲勢主導權 PDI > MDI (多方掌控)
MDI (-DI) Minus Directional Indicator 空方打壓力道 衡量向下摜壓動能，辨別跌勢主導權 MDI > PDI (空方掌控)
ADX Average Directional Index 趨勢總強度 過濾假突破/假跌破，判斷市場是否具備單邊動能 > 25.0 (趨勢成立) / < 20 (無動能)
CHOP Choppiness Index 碎形路徑效率 辨別洗盤絞肉區，識別市場是否在折返跑原地踏步 < 60.0 (趨勢環境) / ≥ 60.0 (泡茶盤整)

2. DMI 體系（PDI 與 MDI）—— 破解 ADX 的「方向色盲」

核心痛點：為什麼不能單看 ADX？

ADX 本身是完全「色盲」的！ 當行情連續急跌暴跌，ADX 會飆高到 40；當行情連續急拉暴漲，ADX 也會飆高到 40。如果 AI 或策略只讀取 ADX，它只知道「現在行情爆大」，但完全無法辨認究竟是大多頭還是大空頭。

數學原理解析

Welles Wilder 透過觀察當前 K 棒邊界相對前一根 K 棒的突破幅度來定義方向位移（Directional Movement）：

+DM = (Today's High - Yesterday's High) > 0 且大於下跌位移時，否則為 0
-DM = (Yesterday's Low - Today's Low) > 0 且大於上漲位移時，否則為 0
PDI (+DI) = 100 × WilderSmooth(+DM, 14) / ATR(14)
MDI (-DI) = 100 × WilderSmooth(-DM, 14) / ATR(14)

實戰交易規則

  • PDI > MDI 買方主導：多方向上突破的動能壓過空方，順勢以逢低做多為主。
  • MDI > PDI 賣方主導：空方向下摜壓的動能壓過多方，順勢以逢高做空為主。
  • 兩線黃金/死亡交叉 往往是日線或小時線級別趨勢反轉的第一個先鋒訊號。

3. ADX 趨勢強度 —— 為什麼單根暴跌大黑K拉不動 ADX？

市場常見的慘劇是：「盤整時突然往下一根 80 點大黑K破底，散戶嚇瘋追空，結果剛好空在全天最低點（阿呆谷），下一秒直接 V 轉拉回！」

在成熟量化體系中，這筆空單會被 ADX 百分之百物理擋下。原因包含三個層面：

層面 1：雙重 Wilder 平滑的數學抑制

ADX 不是即時時速表，而是由兩層 14 週期的指數平滑組成的重型指標：

DX = 100 × |PDI - MDI| / (PDI + MDI)
ADX = WilderSmooth(DX, 14)

Wilder 平滑公式每根 K 棒的新資料權重只有：

Weight(New) = 1 / 14 ≈ 7.14%
Weight(History) = 13 / 14 ≈ 92.86%

若過去 13 根 K 棒都在死魚盤整（ADX 原本趴在 15），突然出現一根暴跌黑K，就像將一滴紅墨水滴進一大桶清水，整桶水稍微變濁，但數值頂多從 15.0 蠕動到 16.5，**完全無法越過 25.0 的趨勢門檻**！

層面 2：微觀結構揭密 —— 那根暴跌黑K究竟是什麼？

既然不是真趨勢，為什麼圖表上會出現大黑K？

  • 掃停損（Stop-Loss Hunt）：箱型盤整時，多數散戶的多單停損市價賣單全都堆疊在關鍵支撐點下方。主力只需用少量籌碼瞬間敲破支撐，就會觸發骨牌效應引發連鎖市價賣出，在 10 秒內打出 50 點長下影大黑K。
  • 真空滑價：在中午流動性匱乏時段，薄弱的買盤委託簿容易因少量拋盤出現短暫價格懸崖。
  • 真趨勢 vs 假洗盤特徵：
    • 真趨勢：主力持續性、多根 K 棒連續大量出貨，ADX 會穩步爬升越過 25。
    • 假破底：單根爆量下殺但隨後成交量急縮，ADX 趴在 20 以下不動。

4. CHOP（Choppiness Index）—— 碎形路徑效率與「泡茶盤」

由 E.W. Dreiss 提出的 Choppiness Index 衡量的是價格走勢的碎形維度（Fractal Dimension），即「累積跑過的總里程」與「起點到終點直線淨位移」的比率。

CHOP = 100 × log10( Sum(TrueRange, 14) / (HighestHigh(14) - LowestLow(14)) ) / log10(14)
「CHOP 40 ~ 65 是盤整區間」這句話對嗎？
不完全正確！ 40 ~ 55 經常包含穩健推進的「慢牛 / 慢熊趨勢」（走 3 步退 1 步）。若將 40 以上都視為盤整，將錯過大部分最穩定的波段利潤。只有 60（或經典 61.8）以上才是嚴禁進場的「真正泡茶盤」。
CHOP 數值區間 市場狀態 實戰意涵 TRIS390 處理邏輯
≤ 40.0 Clean Trend (強勢單邊) 直線噴出或雪崩，能量未被消耗，順勢做單最舒服的黃金期。 全速開單，利潤奔跑
40.0 ~ 60.0 Transitional (過渡整理帶) 包含兩種情境：(1) 急漲後的良性旗型回檔；(2) 盤整末期的三角收斂蓄勢。 放行進場 (< 60)，但建議搭配共振確認
≥ 60.0 Choppy Range (泥淖絞肉區) 多空互扯，過去 14 根 K 棒 60% 以上的能量互相抵消，原地折返跑。 物理鎖死開關 (isTrendingEnv = false)，全面禁止開倉

5. 雙重共振過濾：ADX > 25 與 CHOP < 60 的實戰照妖鏡

在 TRIS390.pine 策略中，將這兩個指標組合為進場的必備門檻：

bool isTrendingEnv = (adxValue > 25.0 and chopValue < 60.0)

將兩者比喻為開車系統：

  • ADX 是「引擎油門深度」：ADX < 20 代表沒有主力踩油門，動力空轉。
  • CHOP 是「方向盤穩定度」：CHOP ≥ 60 代表方向盤左右劇烈打轉，車子原地打滑折返跑。

互為雙重保險的典型場景

  1. 破除誘多陷阱（假突破）：一根長紅拔起，ADX 瞬間被短線拉高到 26（以為要噴了！）；但回頭看 CHOP 依然高達 64（整體結構仍被卡在箱型泥淖內）→ 被 CHOP 擋下，免於追在最高點。
  2. 破除誘空陷阱（假摜破）：突然重挫跌破支撐線；但 ADX 只有 16（完全沒有持續殺盤動量）→ 被 ADX 擋下，免於空在阿呆谷。

6. 週期架構指南（台指期專用實戰規劃）

台指期日盤時間僅 5 小時（08:45 ~ 13:45），不可生搬外匯或加密貨幣的 4H 框架：

交易類型 大週期濾網 (Macro Trend Filter) 執行與觸發週期 (Execution Trigger) 設計原因與操作邏輯
當沖交易 (Intraday)
當天平倉不留倉		 30 分鐘 (30m) 或 15 分鐘 (15m)
ADX > 25 & CHOP < 60		 5 分鐘 (5m) 或 1 分鐘 (1m) 30m 棒子一天只有 10 根，14 週期覆蓋一天半，足以過濾一整天的雜訊。30m 亮綠燈時，在 5m 找拉回均線的順勢上車點。
隔夜短波 (Swing)
留倉 2 ~ 5 天		 60 分鐘 (1H)
ADX > 25 & CHOP < 45		 15 分鐘 (15m) 1H 覆蓋近 3 個交易日。1H 的 CHOP 低於 45 代表跨日級別的大行情發動，不怕盤中洗盤，安心抱單過夜。
避坑警告 請勿在台指期使用 4 小時 (4H) 看 ADX/CHOP。日盤一天僅 1.25 根 4H K棒，計算 14 週期需要近兩週，信號嚴重鈍化，完全無法應對台指當沖與短波。

7. 專案程式碼落地與對齊清單

7.1 Pine 策略端：src/pine/TRIS390.pine

// 盤整過濾設置
useTrendFilter = input.bool(true, "啟用盤整過濾 (ADX & CHOP)", group=grpFilter)
adxThreshold   = input.float(25.0, "ADX 趨勢閥值 (>)", group=grpFilter)
chopThreshold  = input.float(60.0, "CHOP 震盪閥值 (<)", group=grpFilter)

// 運算邏輯
[_, _, adxValue] = ta.dmi(diLength = 14, adxSmoothing = 14)
float trSum       = math.sum(ta.tr, 14)
float rangeDiff   = ta.highest(high, 14) - ta.lowest(low, 14)
float chopValue   = rangeDiff == 0 ? 100 : 100 * math.log10(trSum / rangeDiff) / math.log10(14)

// 趨勢環境總開關
bool isTrendingEnv = useTrendFilter ? (adxValue > adxThreshold and chopValue < chopThreshold) : true

7.2 Python 端：scripts/jev-shadow.py 特徵計算補全

# 1. 計算 DMI 與 CHOP (對標 TRIS390.pine:289-293)
atr14 = _wilder(tr, 14)
pdi, mdi = 100 * _wilder(pdm, 14) / atr14, 100 * _wilder(mdm, 14) / atr14
adx = _wilder(100 * (pdi - mdi).abs() / (pdi + mdi).replace(0, float("nan")), 14)

tr_sum_14 = tr.rolling(14).sum()
range_diff_14 = high.rolling(14).max() - low.rolling(14).min()
chop_ratio = (tr_sum_14 / range_diff_14.replace(0, float("nan"))).clip(lower=1e-9)
chop_14 = 100.0 * (np.log10(chop_ratio) / np.log10(14.0))
chop_14 = chop_14.mask(range_diff_14 == 0, 100.0)

# 2. 注入 state 輸出字典
out.update({
    "average_directional_index_14": _last(adx.iloc[-1]),
    "plus_di_14": _last(pdi.iloc[-1]),
    "minus_di_14": _last(mdi.iloc[-1]),
    "chop_14": _last(chop_14.iloc[-1]),
    "atr14": _last(atr14.iloc[-1]),
})
